## 진행 규칙 (중요 — 반복 사고 방지)

1. **브라우저 측정은 동시에 돌리지 않는다.** 헤드리스 프레임 페이싱이 흔들려 봇 결과가 어긋난다. 실제로 2026-09-18 측정 5e가 다른 워커의 `js/` 수정과 겹쳐 무효가 됐다(`RAudio.staminaEmpty is not a function` 49건). ⇒ 그룹은 **순차**, 각 그룹이 끝나야 다음 그룹이 측정한다.
2. **기존 파일은 Edit(부분 치환)만.** Write 전체 덮어쓰기는 다른 워커의 동시 변경을 지운다. 특히 `js/config.js`.
3. **각 그룹은 아래 게이트를 전부 통과해야 채택.** 하나라도 실패하면 그 그룹 안에서 수치만 조정하고, 5회 안에 못 넘기면 멈추고 실측표와 함께 보고.

| 그룹 | 내용 | 소유 파일 | 상태 |
|---|---|---|---|
| **0** | 스태미너 (엘든링식: 행동 소모·서서히 회복·퍼펙트 환급) | `entities.js` `game.js` `ui.js` `audio.js` `config.js` | 진행 중 |

### 그룹 0 — 스태미너 (버그 수정)
- **왜**: 패리 연타로 보스가 깨지는 결함. 실측 — K+J 연타 24판 중 9승(SERAPH 3/3, BASTION 3/3). 근본 원인은 판정 창 0.34s < 재입력 잠금 0.40s라 헛침의 실질 무방비가 0.06s뿐이고, 블록도 "성공"으로 잠금이 0.10s로 줄어 연타가 끊기지 않는 것.
- **기각된 안**: 단순 쿨타임 연장. `RECOVERY 0.8` → 연타 0/24지만 숙련 봇이 MIRROR 페인트에 죽어 7/8. `RECOVERY 0.6` → 숙련 봇이 BASTION 랠리에 죽어 7/8. **실수 한 번을 과하게 벌해 정상 플레이가 무너진다.**
- **채택 안**: `STAMINA` 블록(MAX/PARRY_COST/DASH_COST/REGEN/REGEN_DELAY/PERFECT_REFUND/EMPTY_FLASH). 퍼펙트만 환급, 블록·헛침은 환급 0. 잔량 부족 시 **입력을 버퍼에 쌓지 않는다**(쌓으면 잠금 해제 순간 자동 재입력돼 연타가 살아남는다).
- **미확정**: `PERFECT_REFUND` 15 vs 30(= 순소모 0). 둘 다 G1~G3를 돌려 통과하는 쪽 채택, 둘 다 통과면 30.

### 그룹 1 — 접근성 2건
- 적 텔이 금 텔과 **같은 원 + 8방사선**이라 색이 유일한 구분(음소거 시). Game Accessibility Guidelines 1급 권고 위반 → 적 텔만 형태 분리(X자 등), 수치는 `TELL` 블록 상수.
- `FX.flashWhite`에 `FX.enabled` 가드가 없어 `?nofx=1`로도 안 꺼짐. 화면 100%·알파 0.85·0.055s이고 SERAPH triple(0.22/0.18s)을 연속 퍼펙트로 받으면 0.44s 안 3회 → WCAG/XAG 118 경계선. `?flash=0` 분리. **히트스톱·흔들림·슬로모·텔 버스트는 끄지 않는다**(판정의 일부).

### 그룹 2 — 게임패드
- 근거: 조사 표본 전부 패드 지원 기본. Steam "Full Controller Support" 필터에서 빠지면 발견성이 떨어지고 Deck Verified 불가.
- **동사는 늘리지 않는다** — 이동/패리/리포스트/대시/확인/재시작 매핑만. `js/input.js`의 `KEYMAP` 옆에 `PADMAP`을 두고 같은 액션 이름으로 합류시킨다. 표준 배치(A=확인, X/□=패리, Y/△=리포스트, B/○=대시, LB/RB 보조, Start=일시정지) + 스틱/D-Pad 이동.
- 헤드리스에서 실제 패드 검증 불가 → `navigator.getGamepads` 모킹으로 액션 매핑만 단위 확인.

### 그룹 3 — 옵션 메뉴
- 상용 최저선: 볼륨·풀스크린·키 리바인드. 현재는 M 음소거 토글뿐.
- **접근성 슬라이더(옵트인)**: 플레이어 HP 배율·보스 windup 배율. 기본값 = 현재 난도. **기본값이 아닐 때는 랭크·트라이 기록을 남기지 않는다**(Celeste Assist 방식 — 코어 난도 무손상).
- **보스 선택**: `?boss=N`이 이미 있음 → 클리어한 보스만 타이틀에서 선택 가능하게 승격. 진행 저장(`localStorage`)과 연동.
- 저장은 기존 `C.STORAGE` 키에 합류.

### 그룹 4 — 아레나·음악·하드 모드
- **아레나**: 현재 8보스 공용 1종(`Render.drawArena`). Titan Souls가 아트 호평에도 "환경이 따분하다"로 감점된 사례 → 챕터/보스별 배경 팔레트·기둥 배치·바닥선을 테이블화. **이미지 에셋 0 유지.**
- **음악**: 현재 2오실레이터 드론 1곡 고정. 보스별 베이스 음정·LFO·컷오프를 `js/bosses/*.js` 로컬 상수로, Phase 2에서 디튠·컷오프 변조. **작곡 없이 파라미터만.**
- **하드 모드 "RIPOSTE+"**: 엔딩 클리어 후 언락. windup 단축·Phase 2 조기 진입·패턴 간격 축소를 보스 테이블 배율로. Furi(Furier)·Katana Zero(Hard)가 "쉬운 옵션 확장"이 아니라 "어려운 옵션 후속 언락"을 택한 관행.
