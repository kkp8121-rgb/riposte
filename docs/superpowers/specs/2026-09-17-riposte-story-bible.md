## 1. 원칙 5 (리듬 보호 — 어기면 대화가 게임을 해친다)

1. **전투 경계에만.** 보스당 `before`(전투 전) 1장 + `after`(승리 후) 1장. FIGHT 안에는 대사 0.
2. **R 재도전 시 반복 없음.** DEFEAT → R 은 INTRO 로 직행. `before` 는 그 보스에 처음 진입할 때만.
3. **한 장면 = 한 화면 ≤ 4줄.** 줄당 한글 30자 안팎. 타자기 연출은 아무 키에 즉시 완성, 완성 상태에서 Enter 로 다음 줄. Enter 길게(0.6s) 또는 Esc = 장면 스킵.
4. **선택지는 두 동사로.** `K = PARRY`(받아넘김) · `J = RIPOSTE`(되받아침). 틀리면 **"TAKEN."** 카드(붉은 비네트, HP 손실 없음) → Enter → 같은 선택지로 복귀. 보스당 최대 1회, 총 3회(VESPER·LANTERN·AVARICE).
5. **`?boss=N` · `?story=0` · 테스트는 전부 건너뛴다.** 봇·스모크 하네스 무영향.

## 2. 적용한 작법 기술 (v3 — 출처: novel/docs)

게임 대사에는 **지문(서술) 채널이 없다.** 소설 기법 중 지문이 하던 일은 실루엣 포즈·화자 라벨·TAKEN 카드·엔딩 카드가 대신한다. 그 전제로 고른 기술만 적는다.

- 길이 지문은 GRAVEN(4.7) ≪ ADAMANT(10.0)·SERAPH(10.3) < 나머지(11~15) 의 3단이다. 나머지끼리는 길이가 아니라 **화계·어미 문자열**로 갈린다(VESPER 하게체 ↔ AVARICE 합쇼체).

- 어미 교차 검사: 12보스의 전속 어미 집합이 서로 겹치지 않는다(`~네` 는 VESPER 하게체와 감탄 해체가 같은 문자열이라 **VESPER 외 사용 금지**). 챕터 3 추가분은 `~지.`(VESPER 가 쓴다) · `~고.`(CHORUS) · `~군.`(BASTION) · 맨 `~다.`(GRAVEN·CHORUS) 를 피해 배정했다 — `~다고.` 는 문자열이 다르다.
- 플레이어: 이름 없음, 말투 없음. 답은 한 단어 6개뿐 — "아직." "절대." "금." "거짓말." "빈손." "전부."

## 4. 줄기 (한 문장)

**모든 보스의 기술도 빼앗은 것이고, 그 사슬의 원점은 "빌려줄 뿐 결코 주지 않는" AVARICE 다.** 챕터 1 은 되찾기(MIRROR = 전부 가진 너), 챕터 2 는 빚의 주인을 만나기, 챕터 3 은 **빼앗기가 통하지 않는 상대**(주지도 않고 되빼앗지도 않고 막아선다). 결말 — 벽까지 넘고 나면, 가져갈 것이 남지 않는다.

- 챕터 제목(UI, 영어 유지): **CHAPTER I — THE HAND** · **CHAPTER II — THE DEBT** · **CHAPTER III — THE WALL**.
- 태그라인 4박: 타이틀 "Nothing is given. Everything is taken." → 엔딩 카드 **"Nothing is kept."**(손패 HUD 가 한 칸씩 비어 간다) → 손패가 다 빈 뒤 **"Nothing is left to take."**(`ENDING.LINE_AT` 마지막 값 2.4 = 손패가 다 비는 2.2s(1.0 + 3×`ENDING_SLOT_DROP`)에서 0.2s 숨 고른 뒤).
- 사슬 공개(after 2줄째): VESPER "스승님 것" → SERAPH "빌린 화살" → GRAVEN "뺏었다" → MIRROR "빌려주기만 하는 사람" → LANTERN "장부" → CHORUS "우리 빚" → BASTION "돈 받는 동안" → AVARICE "대여품". 챕터 3 은 사슬이 아니라 **벽**이다 — SENTINEL "자리" → TEMPEST "버린 나머지" → HOLLOW "빛만 보더라" → ADAMANT "벽도 뺏기는가".
- 예고(after 마지막 줄): 궁수 → 거한 → 거울 → 그 사람 → 둘 → 문지기 → 셈 정확한 사람 → 창 하나(서 있기만) → 폭풍 → 어둠 → 벽 → (엔딩).

## 7. UI·데이터 (구현 계획용)

- 화면: 좌 = 플레이어 실루엣, 우 = 보스 실루엣(기존 `drawBoss`, ×1.6, idle 포즈), 하단 텍스트 박스(화자명 = 보스 색, 본문 백색). CHORUS 는 `/` 앞뒤를 색 2단으로 교대. 배경은 아레나 그대로(추가 그림 0).
- **콜드 오픈**: `before` 1줄째는 화자 라벨을 `???` 로 표시하고, 2줄째부터 보스 이름·색을 켠다.
- **침묵행**: 본문이 `……` 뿐인 줄은 타자기 없이 즉시 표시. Enter 로 넘긴다(자동 진행 없음).
- **소멸 연출**: `dissolve: true` 가 붙은 줄(또는 선택지 reply)은 절반이 찍힌 뒤 실루엣 알파를 0 으로 내린다(`STORY.DISSOLVE: 0.8s`). 문장은 미완결로 남긴다. v4 부터 ADAMANT after 마지막 줄이 이 자리다.
- 폰트: `config.FONT.UI` 스택에 한글 폴백 추가 — `"Malgun Gothic", "Apple SD Gothic Neo", "Noto Sans KR"`. 외부 폰트 로드는 하지 않는다.
- 상수(`config.STORY`): `CPS: 24` · `SKIP_HOLD: 0.6` · `MAX_LINES: 4` · `TAKEN_FLASH: 0.4` · `ENDING_SLOT_DROP: 0.4` · `DISSOLVE: 0.8`.
- 데이터(`js/story.js`, 보스 key 로 조회):
  `{ before: [line…], after: [line…], choice: { at: 'before'|'after', prompt, K: { text, ok, reply }, J: { text, ok, reply } } }`
  — line 은 문자열 또는 `{ text, hideSpeaker: true }` 또는 `{ text, dissolve: true }`. `ok:false` 쪽 reply 가 TAKEN 카드 본문. 문자열은 정의 테이블이므로 `tests/state.mjs` 불변 검사 대상. i18n 이 필요해지면 line 을 `{ ko, en }` 으로 바꾸고 조회 함수 하나만 추가한다.
- 스킵 조건: `?boss=N` · `?story=0` · `game.startBoss(opts.noStory)`. R 재도전은 `noStory` 로 INTRO 직행.
