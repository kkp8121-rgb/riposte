### 남은 과제

- 🔴 **ADAMANT 는 완벽 봇조차 21.4 / 33.2 / 67.7s 로 세 배 갈린다.** 원인은 Phase 2 `counterOnly` 다. 봇은 보스가 idle·recover 일 때만

  경우뿐이다 — 봇에겐 운이다. 사람은 윈드업을 노려 카운터를 넣을 수 있어 봇 실측은 P2 를 비관적으로 잰다. 그래도 "같은 실력인데
  결과가 갈린다" 는 BASTION 과 같은 이봉 신호다. 시도한 두 완화(softMult 0.2 · hp 상향)는 둘 다 기각(레버 8·9). **남은 후보는 설계
  결정이다**: ① 보스별 Phase 2 진입 비율(`phase2At`) 을 두어 ADAMANT 의 P1(결정론 구간)을 길게, P2 를 짧게 — 엔진 한 줄이지만
  기능 추가라 이 태스크에서 넣지 않았다 · ② P2 `wall` 풀 비중 상향(파괴 보상 창 = 확실한 피해 창을 더 자주) · ③ counterOnly 폐기.
